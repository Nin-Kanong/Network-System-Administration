## Create Cristiano Ronaldo in the IT department

``Right-Clicking`` on **IT**:

<img width="905" height="691" alt="image" src="https://github.com/user-attachments/assets/e2862866-777f-4626-bf92-bddb4ffa09ea" />


| Field                          | Value                          |
| ------------------------------ | ------------------------------ |
| First name                     | `Cristiano`                    |
| Initials                       | Leave blank                    |
| Last name                      | `Ronaldo`                      |
| Full name                      | `Cristiano Ronaldo`            |
| User logon name                | `c.ronaldo`                    |
| UPN suffix                     | `@netlab.com`                  |
| Full user principal name (UPN) | `cristiano.ronaldo@netlab.com` |

<img width="435" height="377" alt="image" src="https://github.com/user-attachments/assets/dd7f51c0-e480-4c52-b417-be53c6a354f2" />
