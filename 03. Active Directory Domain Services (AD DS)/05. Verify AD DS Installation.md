<h1 align="center"> Verify AD DS Installation </h1>


---

## WalkThrough 

In this after promoting Windows Server to a Domain Controller, the next step is to verify that Active Directory Domain Services (AD DS) has been installed and configured successfully.

Verification helps confirm that:
- The Active Directory domain has been created.
- The server is operating as a Domain Controller.
- DNS is configured correctly.
- Required Active Directory services are running.
- SYSVOL and NETLOGON shares are available.
- Active Directory diagnostic tests pass.


---

````ps1

````

<img width="585" height="191" alt="image" src="https://github.com/user-attachments/assets/ee111519-8767-40db-b98f-93a90ef175a0" />


| Service    | Full name                        | Purpose                                                    |
| ---------- | -------------------------------- | ---------------------------------------------------------- |
| `NTDS`     | Active Directory Domain Services | Stores and manages Active Directory data.                  |
| `DNS`      | DNS Server                       | Resolves domain names, such as `netlab.com`.               |
| `Netlogon` | Netlogon                         | Handles domain authentication and secure channel services. |
| `DFSR`     | DFS Replication                  | Replicates SYSVOL data between Domain Controllers.         |

4/4 services running

> **Note**: DFSR is used for SYSVOL replication in modern Windows Server deployments. Allow initialization to complete after promotion before expecting SYSVOL replication to be fully operational.

### Verify SYSVOL and NETLOGON Shares

In this we will confirm that the required Active Directory network shares are available.
````ps1
net share
````

<img width="772" height="247" alt="image" src="https://github.com/user-attachments/assets/365909b6-6c5f-41ef-b0cc-b9a66d02eb21" />


| Share name | Resource                                      | Purpose                                                             |
| ---------- | --------------------------------------------- | ------------------------------------------------------------------- |
| `C$`       | `C:\`                                         | Default administrative share for the C drive.                       |
| `IPC$`     | Remote IPC                                    | Supports communication between computers.                           |
| `ADMIN$`   | `C:\WINDOWS`                                  | Remote administration of Windows.                                   |
| `NETLOGON` | `C:\WINDOWS\SYSVOL\sysvol\netlab.com\SCRIPTS` | Stores domain logon scripts.                                        |
| `SYSVOL`   | `C:\WINDOWS\SYSVOL\sysvol`                    | Stores domain policies and scripts distributed to domain computers. |


- ``NETLOGON``: Used to access domain logon scripts.
- ``SYSVOL``: Stores Group Policy files and logon scripts. It is replicated between Domain Controllers.

``NETLOGON`` and ``SYSVOL`` shares found

### Verify DNS Configuration

In this we will confirm that the DNS server can resolve the Active Directory domain.

````ps1
nslookup <Our-domain-name>
````

So in this my domain name is `netlab.com`, so:
````ps1
nslookup netlab.com
````

<img width="442" height="175" alt="image" src="https://github.com/user-attachments/assets/ca160366-f0d8-48a2-ab0e-95326ea36edf" />


> Replace ``Our-domain-name`` with our actual domain, such as ``netlab.com``.

nslookup -type=SRV _ldap._tcp.dc._msdcs.netlab.com
