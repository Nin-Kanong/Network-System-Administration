### Install AD DS using PowerShell

We can also install the same role with one command. This is useful for system administrators who manage multiple servers.


#### Open PowerShell

1. Open the **Start menu**
2. Search for **Windows PowerShell**
3. ``Right-click`` it and choose ``Run as administrator``
4. Approve the User Account Control prompt if it appears.

Check whether AD DS is installed:
````ps
Get-WindowsFeature -Name AD-Domain-Services
````

Look at the Install State column. If it says Available, the role is not installed yet.


#### Install the role and management tools
````ps
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
````

| Command or Parameter | Purpose |
|---|---|
| `Install-WindowsFeature` | Installs Windows Server roles and features. |
| `-Name` | Specifies which role or feature to install. |
| `AD-Domain-Services` | The AD DS role identifier. |
| `-IncludeManagementTools` | Installs associated management tools. |


#### Verify the installation

````cmd
Get-WindowsFeature -Name AD-Domain-Services
````
<img width="1110" height="335" alt="image" src="https://github.com/user-attachments/assets/e96dd385-e984-4153-93e1-5d149be86ff2" />


We can also check which AD DS deployment commands are available:
````cmd
Get-Command -Module ADDSDeployment
````

These commands help confirm that the role and deployment tools are available.
