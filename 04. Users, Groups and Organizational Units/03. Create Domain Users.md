### Create Cristiano Ronaldo

````ps1
$Password = Read-Host "Enter Cristiano's temporary password" -AsSecureString

New-ADUser `
    -Name "Cristiano Ronaldo" `
    -GivenName "Cristiano" `
    -Surname "Ronaldo" `
    -DisplayName "Cristiano Ronaldo" `
    -SamAccountName "cristiano.ronaldo" `
    -UserPrincipalName "cristiano.ronaldo@netlab.com" `
    -Department "IT" `
    -Company "NetLab Company" `
    -Path "OU=IT,OU=Staff,OU=NetLab Company,DC=netlab,DC=com" `
    -AccountPassword $Password `
    -Enabled $true `
    -ChangePasswordAtLogon $true
````

Or in this if we ready have password, use this command:
````ps1
$Password = ConvertTo-SecureString "12345678" -AsPlainText -Force

New-ADUser `
    -Name "Cristiano Ronaldo" `
    -GivenName "Cristiano" `
    -Surname "Ronaldo" `
    -DisplayName "Cristiano Ronaldo" `
    -SamAccountName "cristiano.ronaldo" `
    -UserPrincipalName "cristiano.ronaldo@netlab.com" `

    -Path "OU=IT,OU=Staff,OU=NetLab Company,DC=netlab,DC=com" `
    -AccountPassword $Password `
    -Enabled $true `
    -ChangePasswordAtLogon $true
````

## Assign Manager to users by command:

### Assign Vieira Marcelo as Cristiano Ronaldo's manager

In above we was create user **Cristiano Ronaldo**, so to assign it type, in this first open **PowerShell** as `Administrator`:
````ps1
Set-ADUser -Identity "c.ronaldo" -Manager (Get-ADUser "v.marcelo").DistinguishedName
````
