## Introduction

### Understand the security group design

Here is the group structure we will build.

The purpose of each group is different:


**Global Security Groups (GG)**: Contain the department's users.


**Domain Local Security Groups (DL)**: Receive the Global Groups and will later be assigned permissions on the shared folders.

For each new group:
1. ``Right-click`` Groups.
2. **New** → **Group**.
3. Enter the **group name**.
4. Select **Global**.
5. Select **Security**.
6. Click **OK**.



### Configure Global Group descriptions

Descriptions help administrators understand the purpose of each group.


#### Configure on GG_HR

- ``Right-click`` on **GG_HR**.
- Select **Properties**.
- Open the **General** tab.
- In Description, **enter**:

````
Global Security Group for HR Department Users
````
