<h1 align="center"> Join Windows 11 to Domain </h1>


---

## Introduction

In this we will join two windows 11 pro virtual machines (``CLIENT01`` and ``CLIENT02``) to our existing Active Directory domain, ``netlab.com``.

> We will perform the domain join from each Windows 11 computer using your Windows Server 2025 Domain Controller.


---


### environment

Our Windows Server provides Active Directory Domain Services (AD DS) and DNS. The Windows 11 clients use the server to locate the domain and authenticate domain users.

<img width="714" height="327" alt="image" src="https://github.com/user-attachments/assets/bf6a7516-69aa-49ed-abdb-017f19768806" />


### Network configuration

| Setting         | DC01                   | CLIENT01        | CLIENT02        |
| --------------- | ---------------------- | --------------- | --------------- |
| Computer name   | Actual server hostname | `CLIENT01`      | `CLIENT02`      |
| IP address      | `192.168.10.10`        | `192.168.10.11` | `192.168.10.12` |
| Subnet mask     | `255.255.255.0`        | `255.255.255.0` | `255.255.255.0` |
| Default gateway | Blank                  | Blank           | Blank           |
| Preferred DNS   | `192.168.10.10`        | `192.168.10.10` | `192.168.10.10` |
| Domain          | `netlab.com`           | `netlab.com`    | `netlab.com`    |

> **Note**: Before joining either client, confirm that the server really uses ``192.168.10.10``, its DNS service is running, and both clients use that address as their preferred DNS server.

> **Windows 11 Home** does not support joining a traditional on-premises Active Directory domain.

## Join CLIENT01 to the domain

In this open and login to our normal **CLIENT01** account.

Then open **PowerShell** as `Administrator`.

Then verify it:
````ps1
PS C:\Windows\system32> hostname
DESKTOP-818QI41
PS C:\Windows\system32>
````

So in this my hostname is `DESKTOP-818QI41`.


Then check whether the computer is already domain-joined:
````ps1
PS C:\Windows\system32> get-ciminstance Win32_ComputerSystem | format-list Name,Domain,PartOfDomain


Name         : DESKTOP-818QI41
Domain       : WORKGROUP
PartOfDomain : False
````

So in this it has not joined the domain.



##### Rename the computer

#### Verify domain membership

Open **Command Prompt**.

Then check the **signed-in** user:

````cmd
C:\Users\c.ronaldo> whoami
netlab\c.ronaldo
````
> now we see `netlab\c.ronaldo`.



**Check domain membership:**
````cmd
C:\Users\c.ronaldo> systeminfo | findstr /I /B /C:"domain"
Domain:                    netlab.com
````


Then open **PowerShell**, then check:
````cmd
PS C:\Users\c.ronaldo> get-ciminstance win32_computersystem | format-list name,domain,partofdomain

name         : CLIENT01
domain       : netlab.com
partofdomain : True
````

Now we see `true`.


Now we completed to join domain.
