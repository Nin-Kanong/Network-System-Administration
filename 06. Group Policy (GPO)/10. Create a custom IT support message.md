## Configure a Custom IT Support Notice Using GPO
We will do this entirely through Windows Server graphical tools:
- Active Directory Users and Computers (ADUC)
- Group Policy Management Console (GPMC)
- Group Policy Management Editor
- Windows Client Settings



### Create a custom IT support message

Message 1 – Before Windows sign-in
Custom IT notice
NetLab Company – IT Support
ACCESS RESTRICTION NOTICE

Dear HR User,

Access to Control Panel and Windows Settings is restricted by company policy.

If you require access for an authorized business purpose, please contact the IT Support Team.

Thank you.

Windows displays this message before sign-in.
