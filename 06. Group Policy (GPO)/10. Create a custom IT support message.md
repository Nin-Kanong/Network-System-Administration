## Configure a Custom IT Support Notice Using GPO
We will do this entirely through Windows Server graphical tools:
- Active Directory Users and Computers (ADUC)
- Group Policy Management Console (GPMC)
- Group Policy Management Editor
- Windows Client Settings



### Create a custom IT support message
````
Application blocked
This app has been blocked by your system administrator.

More information – Contact IT Group
Illustrative result. The exact wording and link presentation depend on the Windows version.
NetLab Company – IT Support
CONTROL PANEL ACCESS RESTRICTED

Your account does not have permission to access Control Panel.

Please contact the IT Group if you require access for an authorized business purpose.

Support Team: NetLab IT Group
````

We will configure this manually using GPMC, AppLocker, and a simple internal support webpage. No PowerShell is required.

## Keep Windows Settings blocked

On our previous GPO blocked both Control Panel and Windows Settings.

The AppLocker executable rule above blocks Control Panel, but Windows Settings is a packaged application. It requires a separate Packaged app rule.

Because we will change the previous GPO in the next section, configure this rule too if you want to retain the original HR restriction.


### Create default Packaged app rules

In **AppLocker**, ``Right-click`` on **Packaged app Rules** -> Select **Create Default Rules**:

<img width="1392" height="861" alt="image" src="https://github.com/user-attachments/assets/424f643c-ed2e-4b61-a380-c519d9285a43" />


This creates a default Allow rule for signed packaged apps.

> This is important because once the Executable Rules collection is configured, packaged apps can also be implicitly blocked unless appropriate packaged app rules are created.


### Create a Deny rule for Windows Settings

We need to author this rule on a **Windows 11** machine where the Settings application is installed.


If we cannot see the Settings app in the reference-app list on DC01, install RSAT Group Policy Management Tools on our **Windows 11** management computer through:
