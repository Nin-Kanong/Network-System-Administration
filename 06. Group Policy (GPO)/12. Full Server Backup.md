## 1. Introduction


### The different backup


Before configuring anything, understand these three backup options.

#### A. System State Backup

> Protects Active Directory

Backs up important Windows Server configuration and Active Directory components.

Examples:
- Active Directory database
- SYSVOL
- Registry
- Boot files


#### B. Full Server Backup 

Backs up the complete server, including the operating system, server data, and the critical volumes required for recovery.


#### C. Bare Metal Recovery (BMR)

Protects the critical volumes needed to recover the server when Windows cannot start normally.

## 1. Prepare the Backup Environment

### Plan our backup storage
Before installing the backup feature, prepare a separate backup destination.

Here is the information formatted as a Markdown table:

| Component | Example |
| :--- | :--- |
| **Server** | DC01 |
| **Operating System** | C: |
| **Company Data** | D: |
| **Backup Disk** | E: |
| **Backup Label** | DC01_BACKUP |
| **Backup Tool** | Windows Server Backup |



### Structure
````
DC01
│
├── C:\
│   └── Windows Server
│
├── D:\
│   └── CompanyShares
│       ├── HR
│       ├── IT
│       ├── Finance
│       └── Sales
│
└── E:\
    └── Backup Destination
````

### Create a test file before backup

We must create the file before backing up the server. Otherwise the backup will not contain it.

Create a new folder, just ``Right-click`` an empty area inside ``C:`` -> Select **New** → **Folder** -> Name the **folder**:
````
BackupTest
````
Press **Enter**, then Open the **BackupTest** folder.
our folder location should be:
````
C:\BackupTest
````


The create file in those:
````
Important.txt
````
Content inside:
````
WINDOWS SERVER 2025
FULL SERVER BACKUP TEST

My name: Administrator
Backup Source: C:
Backup Destination: E:

This is my original important file.

I will delete this file after the backup.
Then I will restore it using Windows Server Backup.

Backup Test Version: 1
````

Press `Ctrl + S` to save.
