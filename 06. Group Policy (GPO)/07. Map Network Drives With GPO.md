<h1 algn="center"> Map Network Drives with GPO </h1>


---

We will configure your Windows Server 2025 domain controller (DC01) to automatically map network drives for employees when they sign in to Windows 11 Pro.

I will use your actual SMB share names and Domain Local groups from the PowerShell output you provided.

---


### network drive configuration

Make sure shares are named ``hr``, ``it``, ``general``, and ``Management``.

Use these exact network paths:
| Department | Drive Letter | Network Path        | Target Users    |
| ---------- | ------------ | ------------------- | --------------- |
| General    | `G:`         | `\\DC01\general`    | ``All staff``   |
| HR         | `H:`         | `\\DC01\hr`         | `GG_HR`         |
| IT         | `I:`         | `\\DC01\it`         | `GG_IT`         |
| Management | `M:`         | `\\DC01\Management` | `GG_Management` |

> We will create one GPO and configure four separate drive mappings inside it. Each department-specific mapping will use security-group targeting.



Make sure our AD have like this structure:
````
netlab.com
│
└── NetLab Company
    │
    ├── Staff                     <-- Link GPO here
    │   │
    │   ├── Compliance
    │   ├── Finance
    │   ├── HR
    │   ├── IT
    │   ├── Marketing
    │   └── Sales
    │
    └── Groups
        │
        ├── GG_HR
        ├── GG_IT
        ├── GG_All_Staff
        └── GG_Management
````
