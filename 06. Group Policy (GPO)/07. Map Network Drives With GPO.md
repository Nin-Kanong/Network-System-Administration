## Introduction 


### Map HR and IT Network Drives Using Group Policy (GPO)

We will start with only **HR** and **IT** in our existing netlab.com domain. Once both departments work correctly, We can add Finance, Compliance, Sales, and the other departments.

Make sure shares are named ``hr``, ``it``, ``general``, and ``Management``.


### Structures

````mermaid
flowchart LR
    %% Root Folder
    Root["📁 <b>D:\CompanyShares</b>"]
    
    %% Subfolders
    HR["📁 <b>HR</b>"]
    IT["📁 <b>IT</b>"]

    %% Connections
    Root --> HR
    Root --> IT

    %% Styling
    classDef rootStyle fill:#2d3748,stroke:#4a5568,stroke-width:2px,color:#fff;
    classDef hrStyle fill:#fbd38d,stroke:#d69e2e,stroke-width:2px,color:#744210;
    classDef itStyle fill:#90cdf4,stroke:#4299e1,stroke-width:2px,color:#2a4365;

    class Root rootStyle;
    class HR hrStyle;
    class IT itStyle;
````



#### The group membership structure:

````mermaid
flowchart TD
    %% HR Path
    subgraph HR_Group ["HR Access Path"]
        direction TB
        HR_User["👤 <b>HR User</b>"] --> GG_HR["👥 <b>GG_HR</b><br/>(Global Security Group)"]
        GG_HR --> DL_HR["👥 <b>DL_HR_Modify</b><br/>(Domain Local Security Group)"]
        DL_HR --> HR_Folder["📁 <b>HR Shared Folder</b>"]
        HR_Folder --> H_Drive["💾 <b>H: Drive</b>"]
    end

    %% IT Path
    subgraph IT_Group ["IT Access Path"]
        direction TB
        IT_User["👤 <b>IT User</b>"] --> GG_IT["👥 <b>GG_IT</b><br/>(Global Security Group)"]
        GG_IT --> DL_IT["👥 <b>DL_IT_Modify</b><br/>(Domain Local Security Group)"]
        DL_IT --> IT_Folder["📁 <b>IT Shared Folder</b>"]
        IT_Folder --> I_Drive["💾 <b>I: Drive</b>"]
    end

    %% Styling
    classDef user fill:#3b82f6,stroke:#1e3a8a,stroke-width:2px,color:#fff;
    classDef globalGroup fill:#8b5cf6,stroke:#4c1d95,stroke-width:2px,color:#fff;
    classDef localGroup fill:#ec4899,stroke:#831843,stroke-width:2px,color:#fff;
    classDef folder fill:#f59e0b,stroke:#b45309,stroke-width:2px,color:#fff;
    classDef drive fill:#10b981,stroke:#064e3b,stroke-width:2px,color:#fff;
    
    %% Subgraph Styling
    classDef hrSub fill:#fef2f2,stroke:#fca5a5,stroke-width:2px,color:#7f1d1d;
    classDef itSub fill:#eff6ff,stroke:#93c5fd,stroke-width:2px,color:#1e3a8a;

    class HR_User,IT_User user;
    class GG_HR,GG_IT globalGroup;
    class DL_HR,DL_IT localGroup;
    class HR_Folder,IT_Folder folder;
    class H_Drive,I_Drive drive;
    class HR_Group hrSub;
    class IT_Group itSub;
````
