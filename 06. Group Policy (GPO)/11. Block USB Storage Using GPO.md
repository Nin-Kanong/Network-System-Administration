<h1 align="center"> Block USB Storage Using GPO </h1>



---

We will configure USB storage restrictions in our existing ``netlab.com`` Active Directory environment.

For your first test, we will use:
- **HR (GG_HR)**: USB flash drives blocked.
- **IT (GG_IT)**: USB flash drives allowed.

We will use the normal graphical Group Policy Management Console. No PowerShell or scripts are required.




---



## 1. Prepare Active Directory

### Domain Structure

We will use the OUs and groups we already created.

````
netlab.com
│
└── NetLab Company
    │
    ├── Groups
    │   ├── GG_HR
    │   ├── GG_IT
    │   ├── DL_HR_Modify
    │   └── DL_IT_Modify
    │
    └── Staff
        │
        ├── HR
        │   ├── hr01
        │   ├── hr02
        │   └── hr03
        │
        └── IT
            ├── it01
            ├── it02
            └── it03
````

We will apply the restriction to the HR OU.

Why?

Because our policy will use User Configuration. The user account's location in Active Directory determines which GPO applies.

Therefore:
- HR user accounts receive the restriction.
- IT user accounts do not receive the HR restriction.
- The same HR user is restricted even when signing in to a different domain-joined computer, provided the user GPO applies there.

## 3. Configure USB Write Restrictions


### Enable Removable Disks: Deny write access

Now we prevent HR employees from saving files onto USB storage devices.

This prevents copying company files to a USB drive through normal write access.


Return to the same location:
````
User Configuration
    → Policies
        → Administrative Templates
            → System
                → Removable Storage Access
````
Find:
````
Removable Disks: Deny write access
````

<img width="1555" height="807" alt="image" src="https://github.com/user-attachments/assets/ff647d9a-3fed-4728-8104-fc59ca54fc4d" />


Then `Double-Click` on it, then click `Enabled`:

<img width="856" height="792" alt="image" src="https://github.com/user-attachments/assets/9afaa80d-c5cf-4d07-9569-76706229b683" />


<img width="1567" height="811" alt="image" src="https://github.com/user-attachments/assets/4ddba0a3-9e0f-4da9-8674-7bbf1efbc387" />


Now it `Enabled`.


> **Note**: In this if we want to apply all user can `Enabled` this `All Removable Storage classes: Deny all access`.

**Why in this we don't enabled it?**

> Because that setting blocks all removable storage classes, not just removable disks. It takes precedence over individual removable-storage policy settings. It could also cause unintended restrictions for other devices.
